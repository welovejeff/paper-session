The dictated path

A notebook is what this whole system has been trying to imitate.

A mostly-empty page where your pen is the highest-contrast thing on it, and nothing printed competes with what you write. If you have a notebook and no printer, you already own the good part. What you are missing is the session, and the session can be read out to you.

Two things this page is not for.

  • You have a tablet and a stylus.

    Then this is not a printing problem. Take the PDF and annotate it directly, hue and all — the return half already reads a stylus layer the same way it reads ink on paper, and nothing about the sheet changes.

You have to be the one to say it

The skill never asks whether you can print, and never asks whether you can read the sheet.

Both questions are banned outright, in the reference the skill loads before it designs anything. So the dictated path only ever answers something you said first — which means nothing happens until you say it. Add this to whatever you were already asking for, or send it on its own after a PDF has already turned up.

I can’t print anything today. Dictate this as a card I can copy into the notebook I already have.

Or select the sentence and copy it.

Scope

One sentence covers both reasons because what arrives is the same thing either way: the session written out in plain lines, which is what a notebook wants and also what a screen reader, a slate or a scribe wants. What you then do with it is yours — a notebook, a braille slate, a typed file, a voice memo, somebody writing at your direction.

Asking for the PDF later is fine and is answered without comment. It is never offered unasked, because offering it would name what you are not getting.

Where the loop stands, agent by agent

What arrives

A card in two parts, and only one of them is copied out.

The split is the whole format. One part is transcribed by hand and is the only thing that is; the other is read once, on screen, where it costs no writing. Structure, house rules and the pen legend live in the second part for exactly that reason.

Copy load is stated in words, never in minutes. No card carries a duration, a countdown or a suggested sitting length, because the rule against putting a clock on a page holds off the page as well.

The other reason to take this path

Reading the printed page is a requirement no compatibility row states.

The same card serves someone who cannot read a printed sheet, and the return trip is built to match it. What that costs, and what it does not, is stated in the repository rather than summarised here — because a summary is exactly where a claim like this gets rounded up.

It is not the same session, and nothing on this site is allowed to imply that it is.

The page still comes back

A notebook spread is a valid return, read as carefully as a scan of a printed sheet.

Photograph it and hand it over. With no printed layer there is no printed ink key to consult, so your marks resolve against a legend you wrote on the page and otherwise against the defaults — one gap in the cascade, and nothing else changes.
