Install

Two skills: paper-session prints the page, scan-back reads your handwriting back. Install both, and your AI can offer a page whenever the work turns into a judgment call.

Rather not install? Run a session without it.

In claude.ai or the Claude apps

Download both bundles, then upload each one where the app takes skills. Nothing else to install.

No Node? Clone the repo and unzip the bundles.
