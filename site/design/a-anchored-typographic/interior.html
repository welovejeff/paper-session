Install

Which of these is true of you?

Take both halves or neither. Every sheet prints SCAN IT BACK TO CONTINUE. along its bottom edge, and without the return half that line is a promise nothing keeps.

The directions

01 · Chat app

paper-session.skill
scan-back.skill

Download both and upload them where your client takes skills. No terminal, no unzipping. The skill installs what it needs where it runs.

02 · Terminal or IDE

npx skills add welovejeff/paper-session

Finds both skills in the repository and routes them to Claude Code, Cursor, Codex, Copilot and 70+ other agents. Project-level by default; -g installs user-level.

03 · No Node

git clone https://github.com/welovejeff/paper-session.git
cd paper-session
unzip -o paper-session.skill -d ~/.claude/skills/
unzip -o scan-back.skill -d ~/.claude/skills/

The bundles are ordinary zips. Whatever unpacks an archive on your machine is enough.

04 · No skills runtime

paper-session-paste.md
scan-back/SKILL.md

Nothing installs, because nothing reads a skills folder. Paste the forward file, say what you are working on, and add the sentence in the box below. What comes back is a card you copy into a notebook by hand, never a PDF.

I can't print, and you can't make a PDF here, so dictate the setup card for me to copy by hand — there is nothing to annotate.

That sentence is load-bearing: it is what routes the host onto the setup-card path.

Python

python3 -m pip install -r ~/.claude/skills/paper-session/requirements.txt

reportlab draws the page. pdfplumber runs the layout gate no sheet is allowed to skip. Point pip at the copy that arrived with the skill. Add --break-system-packages where pip reports the environment is externally managed. Nothing to install on a chat surface; nothing at all on the paste route, which renders no file.
