00 The problem

Where does the machine stop and you start?

Verbatim · README.md

In agentic workflows the bottleneck is no longer AI output. It’s your ability to metabolize that output. When a task reaches work that is genuinely yours — sequencing, weighing tradeoffs, naming something, deciding what matters — the right move is to stop generating and get off the screen.

02 The one rule

Whose thought does this slot belong to?

Verbatim · README §The one rule

The AI contributes where it has done work worth reacting to — a proposed order, gathered options, a draft sequence, one well-chosen analogy. Print it so you can re-rank it, cross it out, argue with it in the margin.

Verbatim · README §The one rule

The AI withholds where you are better — creative generation, judgment calls, naming, deciding what matters. Print the provocation. Leave the space empty. When in doubt, withhold.

Verbatim · README §The one rule

Design fixation is the most replicated finding in design cognition: show someone an example and their ideas come to resemble it, producing fewer ideas across fewer distinct categories. Telling them not to copy does not fix it — groups instructed to avoid an example incorporated its features at the same rate as groups given no instruction at all.

•Black · note Which is why the empty half of sheet A is empty. Instruction cannot do that job. Layout can.

03 The evidence

How much of this is known?

Verbatim · README §Why paper — three numbers

d = 0.93

Walking’s effect on divergent thinking, meta-analytic across 23 studies. It persists after you sit back down, which means a walk before a Deep sheet may be worth as much as the sheet.

58%

More ideas produced by employees given unexpected idle time, in a natural experiment at real work.

Held steady

In an AI-assisted design study, output quality and ideational diversity fell while participants’ self-assessed creativity did not move.

Verbatim · README §Why paper

The tools degrade the work and leave the confidence intact, and paper is where you find out.

?Red · review No study tests this artifact. There is no research on AI-generated worksheets completed offline and returned. Six more limitations are written down, including a failed replication at N = 443.

!Red · priority A paper session will feel less productive than the same hour on screen, including on the days it is most productive.
