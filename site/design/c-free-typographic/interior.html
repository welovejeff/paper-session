02 The routes

Is there a file picker, a terminal, or only a text box?

  • A Chat app

    Can you attach a file to it?

    Verbatim · README §Install

    Download the two packaged bundles and upload them where your client takes skills. No terminal, no unzipping:

    paper-session.skill
    scan-back.skill

    Nothing to install by hand on a chat surface, where the skill runs its own Python.

  • B Terminal or IDE

    Do you have a shell?

    Verbatim · README §Install

    The skills CLI finds both skills in this repo and routes them to Claude Code, Cursor, Codex, Copilot, and 70+ other agents:

    npx skills add welovejeff/paper-session

    Project-level by default; -g installs user-level. No Node? The bundles are ordinary zips — clone and unzip into your skills directory.

  • C No skills runtime

    Only a text box?

    Verbatim · README §Install

    ChatGPT, Gemini, Copilot chat, Perplexity, Le Chat, DeepSeek, Grok, Poe. There is nothing to install and one file to paste: paper-session-paste.md. Paste the whole file into the chat, say what you’re working on, and add this sentence:

    I can’t print, and you can’t make a PDF here, so dictate the setup card for me to copy by hand — there is nothing to annotate.

?Red · review, on route C A pasted protocol is user text with no standing against the host’s own system prompt. A model tuned to be maximally helpful can still pre-fill a zone or volunteer a duration that the rules in the paste forbid. How often, on which product, is unmeasured.

03 The words in the ledger

What has to be true before a row gets its word?

✓ Verified end to end
Someone installed both halves on that agent, generated a sheet, printed it, filled it in with a pen, photographed the page, and had the work resumed from the photograph. One agent qualifies.
• Supported, not verified
The path the return trip was designed around, and where the skill installs what it needs on its own. No tested loop is claimed on it, so the ledger does not give it the same word.
? Installs cleanly, loop untested
Discovery and install work. Whether that agent can run reportlab and read a photograph back afterwards is not known, because nobody has tried it and written it down.
? Untested, per surface
Nothing is rendered, so nothing is verified. The forward half produces a hand-copied card rather than a PDF, and there is no layout gate because there is no file. Each host is its own case.

05 Python

Who draws the page, and who checks the drawing?

Verbatim · README §Install

reportlab draws the sheet; pdfplumber runs verify_layout.py, the layout gate no sheet is allowed to skip. The list ships inside the bundle, so point pip at the copy that arrived with the skill rather than at this repo:

python3 -m pip install -r ~/.claude/skills/paper-session/requirements.txt

•Black · note Add --break-system-packages where pip reports the environment is externally managed.
